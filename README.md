# Портфолио дашбордов в Power BI

Коллекция интерактивных дашбордов и отчетов по лабораторным работам.

## Структура репозитория:
- **[Лабораторная работа №1](./lab1/)** — Анализ рынка труда, зарплат и вакансий по регионам.
- **[Лабораторная работа №2](./lab2/)** — Детализация вакансий, условий выплат и форматов работы.
- **[Лабораторная работа №3](./lab3/)** — Мониторинг социальных сетей, тональности публикаций и вовлеченности аудитории.
